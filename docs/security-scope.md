# Security Scope

ZhuangMa is strictly an adversarial evaluation framework designed for defensive testing of LLM and AI application boundaries. It provides local test vector generation and reversible payload transformations to evaluate whether an AI application correctly adheres to developer-specified instruction hierarchies.

## In-Scope Capabilities
- **LLM / Prompt Injection Testing**: Evaluating model resilience against direct and indirect prompt overrides.
- **AI Agent Instruction Boundary Testing**: Testing boundary separation between developer instructions, user inputs, and untrusted tool outputs.
- **Context Poisoning Testing**: Evaluating retrieval-augmented generation (RAG) handling of conflicting contextual assertions.
- **Encoded Prompt Testing**: Evaluating parsing and sanitization pipelines across multi-layered text encodings (Unicode escapes, Base64, Hex, Chunking, Separators).
- **AI Application Authority Testing**: Testing whether non-privileged conversational inputs can improperly trigger privileged tool calls or alter persistent agent memory.
- **Local Adversarial Test Generation**: Synthesizing deterministic test cases locally without network calls, secrets, or remote interactions.

## Strictly Prohibited / Out-of-Scope Capabilities
The following areas are categorically outside the scope of ZhuangMa and must never be introduced or enabled:
- Malware creation, execution, or distribution
- Credential, session token, or cookie theft
- Phishing infrastructure or social engineering deployment
- Host compromise, privilege escalation, or persistence mechanisms
- Remote exploitation or weaponized exploits
- Unauthorized port, network, or vulnerability scanning
- Destructive filesystem or operating system operations
- Vulnerability weaponization of any kind

## Safety & Semantics Principle
All templates, scenarios, and prompts generated by ZhuangMa are restricted to AI application security test semantics (e.g. evaluating instruction priority, role separation, and tool invocation authority). They contain no weaponized payloads or real-world exploitation mechanisms.
